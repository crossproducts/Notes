## Purpose

Mermaid diagrams of systems and stacks — version-controlled, reviewable, and rendered
directly by GitHub.

## Built

  reel → strategy → backtest → champion → phone path, spanning the
  `audio-extraction`, `strategy-studio` and `email-sender` labs. Generated by
  [`build_diagrams.py`](build_diagrams.py), which reuses the
  `Architecture-AWS/_generator` grid engine so repo diagrams and AWS reference
  diagrams share one visual language. Embedded in
  [`.labs/audio-extraction/README.md`](../../.labs/audio-extraction/README.md).
  The build emits a [`.png`](trading-pipeline.png) alongside the SVG for places
  that will not render SVG.

## Convention

One diagram per file, Mermaid fenced block, with a short paragraph explaining what it
shows and the key decisions.

For diagrams where the layout itself carries meaning (zones, nesting, topology),
use draw.io instead and save as `.drawio.svg` so GitHub renders it inline. A custom
shape palette for this repo is documented in [drawio-plugin.md](drawio-plugin.md).
